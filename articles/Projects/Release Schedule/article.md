#Grappleverse set release schedule

---

The following table presents a chronological release schedule for all sets in the Grappleverse, along with accompanying information regarding the set structure, associated release block, et cetera. As is the case throughout the Hub, unfinished and unreleased sets are marked with a common expansion symbol, while finished and released sets are denoted with a mythic rare expansion symbol. Release years are provided as a reference point and the chronology of the table indicates release order, but no set is truly "finished" in that tweaks and polishes are still always possible, so this information represents only the initial stable release version.
